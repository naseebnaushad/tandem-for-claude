## 1. Summary
Tandem for Claude lets you use several Claude seats on one computer, side by side,
without logging out and without losing chats. Each **profile** is its own Claude desktop
window or Claude Code terminal with its own sign-in, and every profile sees every
Code-tab chat. You can start a chat on one seat and continue it on another. It's for
anyone with more than one Claude seat, for example two Team seats.

This is the first public Beta. It works on macOS. Windows and Linux builds are available
but haven't been tried on a real machine yet.

**Highlights**
- Several Claude seats open at once, each staying signed in.
- Every Code-tab chat visible in every profile, kept in sync in the background.
- Downloads for macOS, Windows and Linux.

## 2. What's new
| # | Feature | What it does for the user | Area |
|---|---|---|---|
| N-01 | Named profiles | Create as many profiles as you like with any name. A **Desktop** profile is a separate Claude window; a **Terminal** profile is Claude Code in a terminal. Each keeps its own sign-in. | Profiles |
| N-02 | Chat sync | Copies each chat's list entry between profiles, so every profile lists every Code-tab chat and can continue it. Runs every 5 minutes (you can change this) and on **Sync now**. | Sync |
| N-03 | Sign-in helper | First sign-in of a desktop profile in one guided step. Claude sends sign-ins to the first open window, so the helper closes the others for a moment and reopens them afterwards. | Profiles |
| N-04 | Window and tray icon | Profiles, sync status, backups and settings in one window. Open any profile from the tray or menu bar. | App |
| N-05 | Backups | The chat lists are backed up before every change (newest 20 kept) and can be restored from the app. | Sync |
| N-06 | Keep old chats | Optionally raise how long Claude Code keeps chats (it deletes them after 30 days by default). | Settings |
| N-07 | Start at login | The app can start hidden at login and keep syncing. | Settings |
| N-08 | Command line | `tandem status`, `tandem sync --apply`, `tandem profile …`, `tandem backups …`, `tandem retention …` in the same program. | App |
| N-09 | Downloads for three systems | macOS (Apple Silicon and Intel), Windows x64 (installer or portable) and Linux x86_64 (AppImage or archive). | Release |

## 5. Security
- Never deletes anything from Claude's folders. Deletes carry over as markers.
- Never reads or copies sign-ins, tokens, cookies or the keychain.
- Makes no network requests of its own.
- Pauses sync if Claude's file format changes, instead of guessing.
- Writes are atomic, and new files never overwrite existing ones. Files are private to
  your user account.
- Backups are checked for unsafe paths before restoring.
- The window shows text safely and runs only the app's own code.
- Vulnerability scans (`govulncheck`, `npm audit`) found nothing. A secret scan found
  nothing.

## 6. Breaking changes and upgrade steps
None. If you used the earlier command-line test tool (`claude-profile`), the app adopts
its profiles, backups and sync state on first start, and removes its background job
automatically.

## 7. Known issues
| # | Issue | Workaround | Planned fix |
|---|---|---|---|
| K-01 | Continuing a chat on another seat hasn't been confirmed end to end yet (desktop and terminal). | Keep a backup; report what you see. | Confirm during Beta (SYNC-M04, PROF-M07) |
| K-02 | Windows and Linux haven't been tried on a real machine. | Use and report issues. | Beta testing |
| K-03 | Linux has no official Claude desktop. Desktop profiles need a community build; Linux packages need GTK 4 / WebKitGTK 6.0 (e.g. Ubuntu 24.04+). | Use terminal profiles. | Follows Anthropic's releases |
| K-04 | Builds aren't code-signed. | macOS: right-click → Open the first time. Windows: More info → Run anyway. | Signing only if users ask |
| K-05 | New chats appear in a Claude window only after that window restarts. | Restart the window, or just open the chat later. | Limited by how Claude reads its list |
| K-06 | Sidebar layout (projects, groups, pins) is separate in each desktop window. | Set it up once per profile. | — |
| K-07 | Every desktop window has the same Claude icon. | Tell them apart by the account shown, or open them from the tray. | — |
| K-08 | Two seats writing the same chat at once can mix up its messages. | Keep one chat open in one profile at a time; the Sync tab warns. | — |
