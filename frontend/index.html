Tandem for Claude

Each profile is its own Claude window or terminal with its own sign-in. Every profile sees every Code-tab chat.

Claude desktop wasn't found on this computer. Terminal profiles still work.

-

New chats appear in a Claude window after you restart that window. Claude reads its chat list when it starts.

Warnings

    A backup of every chat list is taken before each sync that changes something. The newest 20 are kept. To restore one, quit every Claude window first.

      Keep old chats

      Claude Code itself deletes chats older than this many days (its default is 30), whichever profile they came from. This changes cleanupPeriodDays in Claude Code's settings; your other settings are kept.

      Keep one chat open in only one profile at a time. Two seats writing the same chat at once can mix up its messages.
